# 💬 Simple AI Chatbot

**Project #01 of the 100+ AI Projects series — by Aryan Kumar Shah**

A simple, offline AI chatbot. No API key, no login, no internet needed.
It understands greetings, questions about Python / Java / C, jokes, motivation, time and date.

## What it can do
- Chat with a clean, modern UI — bubbles, typing indicator, suggestion chips
- Rule-based brain: matches what you type to the right answer
- Works as a website AND as an installable app (PWA — install from your browser menu on phone)
- Python version included, with the same answers as the web version

## Try it
**Website:** Open `index.html`, or enable GitHub Pages on this repo and open the live link.
**App:** Open the live link in Chrome on your phone → menu → "Add to Home screen" / "Install app".
**Python:**
```bash
python chatbot.py
```
Then type `hello`, `python tip`, `joke`, `motivate me`, or `bye`.
