## Full description (README / portfolio / LinkedIn post)
Simple AI Chatbot is Project #01 of my 100+ AI Projects series. It is a rule-based chatbot that works completely offline — it matches what you type to the right answer, so it needs no API key, no login and no internet.

It can greet you, explain Python, Java and C tips, tell jokes, motivate you, and tell the time and date. The web version has a modern chat UI with typing effect and suggestion chips, installs as an app on your phone, and the same brain is also included as a Python CLI version.
